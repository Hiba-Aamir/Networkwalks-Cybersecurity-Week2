## 🔍 Key Highlights & Phases Covered

* **Phase 1 – Reconnaissance & OSINT:** Conducted passive and active footprinting on authorized targets (`networkwalks.com` and `microsoft.com`) to gather domain metadata, DNS records, web technologies, WAF configurations (ModSecurity), and sub-domains.
* **Phase 2 – Network Discovery:** Scanned the local LAN subnet (`192.168.1.0/24`) using Zenmap to identify 8 active live hosts, inspect MAC vendors, and generate a graphical network topology.
* **Risk & Remediation:** Documented potential security exposures (CMS version disclosure, open endpoints) alongside actionable hardening recommendations.
